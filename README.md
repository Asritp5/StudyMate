# 📚 StudyMate

**StudyMate** is a collaborative web application designed to help users connect with like-minded peers in dedicated chatrooms. Users can create or join discussion rooms, share ideas, and build productive study communities. With user-friendly authentication and profile customization, StudyMate makes online collaboration seamless and engaging.

---

## 🚀 Features

- 🔐 User Authentication (Login & Registration)
- 🏠 Create, join, and delete chatrooms
- 💬 Post, edit, and delete comments in rooms
- 🧑‍💼 Setup and manage user profiles (bio, profile picture, etc.)
- 🎯 Connect with peers sharing similar interests

---

## 🛠️ Tech Stack

- **Frontend**: HTML, CSS, JavaScript  
- **Backend**: Python, Django  
- **Image Handling**: Pillow (for profile pictures)
